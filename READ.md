# Очередь на массиве (кольцевой буфер)

Реализация очереди на языке C с фиксированным размером на основе кольцевого буфера.

## Операции

- `enqueue` — добавить элемент в конец очереди
- `dequeue` — извлечь элемент из начала очереди
- `peek` — посмотреть первый элемент без извлечения
- `isEmpty` — проверка на пустоту
- `isFull` — проверка на заполненность
- `display` — вывод содержимого очереди

Все операции выполняются за O(1).

## Структура проекта

- `queue.h` — заголовочный файл с объявлением типов и функций
- `queue.c` — реализация очереди
- `main.c` — пример использования

## Сборка и запуск

gcc main.c queue.c -o queue
